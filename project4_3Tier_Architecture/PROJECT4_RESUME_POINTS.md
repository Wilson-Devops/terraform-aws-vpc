# Resume Points – AWS 3 Tier Architecture

## Project Title

AWS 3-Tier Architecture using Terraform

---

## Description

Designed and deployed a highly available 3-tier architecture on AWS using Terraform.

Implemented secure network segmentation with public and private subnets, NAT Gateway, Security Groups, Application Load Balancer, EC2 instances, and Amazon RDS MySQL.

---

## Responsibilities

- Created VPC and subnet architecture
- Configured Internet Gateway and NAT Gateway
- Implemented Security Groups and Bastion Host
- Provisioned EC2 instances using Terraform
- Configured Apache Web Servers
- Deployed Python-based Application Servers
- Implemented Application Load Balancer and Target Groups
- Created Amazon RDS MySQL database
- Established secure App-to-Database connectivity
- Performed infrastructure validation and troubleshooting

---

## Technologies

AWS, Terraform, EC2, VPC, ALB, RDS, IAM, Security Groups, Route Tables, NAT Gateway, Linux, Apache, Python, MySQL

---

## Key Achievements

- Built complete production-style 3-tier architecture
- Implemented secure private subnet design
- Automated infrastructure provisioning using Terraform
- Configured ALB and RDS integration
- Demonstrated end-to-end application flow across all tiers
